# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. One drawing in, a reviewable report out. Then the stake: Rules get 87.5%. The head gets 100%. On synthetic drawings. Is that number honest?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the race: Heuristic rules 87.5%, EfficientNet-B0 head 100.0%; EfficientNet-B0 head wins, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. First sample, an elevation: report, then walls in red OCR with confidence, then the JSON report The floor plan: five rooms, five dimensions
4. **The answer** (68 to 90 s): 100%, held-out accuracy · synthetic drawings · rules 87.5%. No mock boxes left. And it ships. One limit: Every image is drawn, not scanned. Real scans untested. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
